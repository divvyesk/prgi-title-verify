# Synthetic Native Title Dataset

This dataset (`native_sample.csv`) contains 200 synthetic rows of Hindi, Marathi, and Tamil titles.

**IMPORTANT DECLARATION:**
1. This data is generated by back-transliterating Latin-script records into Devanagari and Tamil scripts.
2. Back-transliteration is inherently lossy and imperfect.
3. These are **NOT real registry records** in their native script forms.
4. They exist purely to demonstrate the cross-script matching pipeline (e.g., verifying that a query in Devanagari matches a registered title in Latin script).

When loaded into the database, these records are marked with `source = 'SYNTHETIC_NATIVE'` so they can easily be filtered out of any real accuracy measurement.
